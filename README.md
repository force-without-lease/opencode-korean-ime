# opencode-korean-ime

opencode TUI 입력창에서 영문 자판으로 친 키를 두벌식 한글로 조합하는 플러그인입니다.

리눅스 콘솔이나 kmscon처럼 시스템 입력기가 없는 환경, 또는 한글 입력이 안 되는 기기에서 원격으로 접속해 opencode를 쓰는 경우를 위해 만들었습니다. 일반 데스크톱 터미널에서는 시스템 입력기를 그대로 쓰면 됩니다.

## 설치

저장소를 opencode 설정 폴더 아래로 받습니다.

```sh
git clone https://github.com/force-without-lease/opencode-korean-ime ~/.config/opencode/plugins/opencode-korean-ime
```

`~/.config/opencode/cli.json`의 `plugins` 목록에 경로를 추가합니다.

```json
{
  "plugins": ["./plugins/opencode-korean-ime"]
}
```

opencode 창을 다시 열면 적용됩니다. opencode v2.0.30에서 확인했습니다.

## 사용법

| 키 | 동작 |
|---|---|
| `Ctrl+Space` | 한글과 영문 전환, 처음 상태는 한글 |
| 영문 자판 키 | 두벌식 배열로 한글 조합 |
| `Backspace` | 조합 중인 음절을 한 타씩 삭제 |

- `/`로 시작하는 명령은 영문 그대로 입력됩니다.
- 한 문장 안에서 `Ctrl+Space`로 전환해 가며 한글과 영문을 섞어 쓸 수 있습니다.

## 조합 규칙

시스템 한글 입력기와 같은 방식으로 동작합니다.

- 조합 중인 음절은 하나뿐이고, 다음 음절이 시작되면 앞 음절이 확정됩니다.
- 받침 뒤에 모음이 오면 받침이 다음 음절의 초성으로 넘어갑니다. `닭`에 `ㅏ`를 치면 `달가`가 됩니다.
- 겹모음(`ㅘ`, `ㅢ` 등)과 겹받침(`ㄺ`, `ㅄ` 등)을 조합합니다.
- `Shift`를 누르면 된소리(`ㄲ ㄸ ㅃ ㅆ ㅉ`)와 `ㅒ`, `ㅖ`가 입력됩니다.
- 백스페이스는 조합 중인 음절 안에서만 한 타씩 되돌립니다. `과`는 `고`, `ㄱ` 순서로 지워지고, 확정된 글자는 한 글자씩 지워집니다.
- 커서를 옮기거나, 메시지를 보내거나, 붙여넣기나 되돌리기로 내용이 바뀌면 조합이 끝납니다.

## 테스트

```sh
bun test
```

## 호환성

- opencode가 키 입력 처리 방식을 바꾸면 동작이 달라질 수 있습니다.
- 프롬프트 외의 입력창(검색 대화상자 등)에서도 한글로 조합됩니다. 영문이 필요하면 `Ctrl+Space`로 전환해서 쓰면 됩니다.
